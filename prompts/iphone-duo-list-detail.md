# iPhone Duo 任務 2：列表／詳情導覽

## 目標

在寬視窗中並排瀏覽列表與選取內容；縮窄後仍能繼續閱讀目前內容並返回列表，搜尋與篩選不因視窗大小變動而重置。

## 範圍（這個 Phase 只做這些）

- 道具搜尋 → 道具詳情、藏寶圖 → 地圖詳情、發光武器系列 → 系列詳情、戰鬥職業 → 技能循環編輯器。
- 四組導覽共用可自動收合的系統雙欄容器；首頁進入功能後，列表可返回首頁。
- 詳情未選取時顯示本地化提示；寬畫面可更換選取，窄畫面可返回列表。
- resize 保留同一功能的選取、搜尋、篩選、排序與正在瀏覽的詳情導覽。
- 切换列表選取時重設該詳情的局部導覽，避免新選取顯示舊內容。

## 不在這個 Phase

- 技能循環編輯器內的雙區佈局（任務 3）。
- 篩選器改為 popover（任務 4）、地圖與資訊並排（任務 5）。
- 調整首頁卡片、資料生成器、儲存格式、部署版本或裝置方向宣告。
- 跨 app 重啟或返回首頁後還原目前導覽；這裡的狀態保留限於同一次功能使用期間的 resize。

## 資料來源與導覽

沿用既有各功能 ViewModel 與 bundled data。選取使用道具 Int ID、地圖 String ID、武器系列 String ID、職業 Int ID。
搜尋或篩選讓所選列暫時不在結果中時，已開啟的詳情仍保留，直到使用者選取另一列或返回列表。
藏寶圖區域／寶點與道具素材的次級導覽在詳情欄內進行。

## Resizability 參考

參考 Xcode 27.1 的 `app-resizability` skill。以目前容器的空間與系統 size class 決策，不讀取全域螢幕、裝置型號或方向來決定欄數；讓系統處理各欄 safe area。
同一導覽容器在 resize 時持續存在，不能透過寬／窄兩套條件式 view tree 重建 ViewModel。

## 驗收

- **AC-1** `[人工]` Duo 展開的寬畫面中，四組功能各自可同時顯示列表與選取內容。
- **AC-2** `[人工]` 窄畫面中，四組功能點擊列後顯示詳情，返回操作可回到該列表。
- **AC-3** `[人工]` 未選取時，寬畫面詳情欄顯示選取提示。
- **AC-4** `[人工]` 寬畫面選取另一列後，詳情更新為新選取，無前一項的次級詳情殘留。
- **AC-5** `[人工]` 窄／寬切換後仍呈現原本選取的道具、地圖、武器系列或職業。
- **AC-6** `[人工]` 道具搜尋文字與已設篩選在 resize 後保留。
- **AC-7** `[人工]` 藏寶圖篩選與排序在 resize 後保留。
- **AC-8** `[人工]` 道具素材與藏寶圖區域的次級導覽在 resize 後可繼續閱讀並返回。
- **AC-9** `[人工]` 列表上的返回首頁操作可回到首頁，五個首頁功能皆可再次進入。
- **AC-10** `[diff]` resize 不重建功能的 ViewModel，不因 resize 主動清除選取或搜尋狀態。
- **AC-11** `[diff]` 新增使用者可見文字均經 L10n 與 Localizable.xcstrings 提供繁中／英文。
- **AC-12** `[diff]` 保持 iOS 17、Swift 5.9，並且不引入裝置型號、全域 screen 或方向判斷來決定佈局。

驗證執行專案生成、Simulator build 與 `scripts/run_tests.sh`；此項以系統導覽與畫面互動為主，人工項逐條記錄實際測試結果，無法驗證的項目明確標示。
