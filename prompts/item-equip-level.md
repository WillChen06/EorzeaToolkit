# 道具搜尋：裝備等級

## 目標

道具搜尋可以用裝備等級篩選，例如只看 80 級能穿的裝備。現在只能用品級（iLv）篩，這是不同的東西。
搜尋結果和 detail page 也顯示裝備的裝備等級，不用 filter 也看得到。

## 範圍（這個 Phase 只做這些）

- `build_items.py` 讀繁中 `Item.csv` 的 `Level{Equip}`，寫成 `items.json` 每筆道具的 `equip_level`。
- `data_revision` 改為 3，重新產出資料（`items.json` 與 `build/remote-data/` 的遠端副本）。
- App 的道具 model 讀 `equip_level`。
- 道具搜尋的 filter 新增「裝備等級」範圍 1–100，預設 1–100（等於不篩）。範圍不是 1–100 時，只留下可裝備的道具（見「Filter 行為」）：
  - filter 畫面在「品級 (iLv)」下方新增「裝備等級」區塊，操作方式與品級相同：顯示目前範圍，下限、上限各一個滑桿。
  - 啟用中的 filter 數、filter 摘要、重設 filter 都包含裝備等級。
- `validate_data.py` 檢查 `equip_level`。
- 搜尋結果列表與 detail page 的等級文字，可裝備的道具加上裝備等級（見「顯示」）。

## 不在這個 Phase

- 依職業或角色等級自動帶入範圍。
- 用描述搜尋（Foundation Models）。
- 上傳遠端資料到 Cloudflare：內建的 r3 比遠端新，App 不會下載遠端那份。

---

## 資料來源

- 繁中 `Item.csv` 的 `Level{Equip}`：裝備或使用這個道具需要的等級。`items.json` 收錄的 45,853 筆全部 ≥ 1。
  - 可裝備的道具（`equip_slot` ≠ 0）27,125 筆，範圍 1–100。
  - 不可裝備的道具大多是 1。例外：
    - 釣餌（99 筆）：值是使用等級。
    - 停止流通道具（1,205 筆）：大多是舊裝備。
    - 套裝（11 筆）。
  - filter 與顯示只用可裝備道具的這個值；不可裝備道具的值照樣寫進資料，但 filter 不看，畫面也不顯示。
- 不要和 `Level{Item}`（品級，現有的 `ilvl`）搞混。
- 等級上限提高（新資料片）時，filter 的上限 100 要跟著改。資料超過 100 時，`validate_data.py` 會失敗並提醒。

## Filter 行為

- 範圍是 1–100（預設）時不篩，任何道具都不受影響。
- 範圍不是 1–100 時，只留下可裝備（`equip_slot` ≠ 0）、而且裝備等級在範圍內的道具。
  不可裝備的道具（材料、藥品、釣餌、停止流通道具等）都從結果拿掉。
- 範圍包含上下限本身：設 80–80 時，只留下裝備等級剛好 80 的道具。
- 下限不能大於上限，上限不能小於下限。調整方式和品級一樣。
- 摘要格式與品級相同，例如「裝備等級 80-100」。

## 顯示

- 可裝備的道具（`equip_slot` ≠ 0）：「Lv.<裝備等級> · iLv <品級>」，例如「Lv.100 · iLv 700」。
  搜尋結果列表與 detail page 用同一個格式。
- 不可裝備的道具：維持「iLv <品級>」，例如釣餌「iLv 430」。釣餌的值是使用等級，不是裝備等級，不顯示。
- 可裝備但資料沒有裝備等級（值是 0）時，也只顯示品級。

## 驗收

- **AC-1** `[自動]` `items.json` 每筆道具都有 `equip_level`，是 1–100 的整數 —— `validate_data.py`
- **AC-2** `[自動]` 設定裝備等級範圍後，可裝備的道具只留下裝備等級在範圍內（含上下限）的 —— 新增 unit test
- **AC-3** `[自動]` 裝備等級不是 1–100 時，不可裝備的道具不在結果裡 —— 新增 unit test
- **AC-4** `[自動]` 裝備等級維持 1–100 時，搜尋結果與沒有這個 filter 時相同，包含不可裝備的道具 —— 新增 unit test
- **AC-5** `[自動]` 裝備等級不是 1–100 時算一個啟用中的 filter，回到 1–100 時不算 —— 新增 unit test
- **AC-6** `[自動]` 裝備等級不是 1–100 時，filter 摘要顯示該範圍，回到 1–100 時不顯示 —— 新增 unit test
- **AC-7** `[自動]` 重設 filter 後，裝備等級回到 1–100 —— 新增 unit test
- **AC-8** `[人工]` filter 畫面在「品級 (iLv)」下方顯示「裝備等級」，可以分別調整下限與上限，下限不會超過上限。
- **AC-9** `[人工]` 抽查 5 個可裝備的道具（至少含 1 個武器、1 個飾品），把裝備等級設成該道具在遊戲內的等級時，搜尋得到它。
- **AC-10** `[人工]` 與目前的 `items.json` 相比，每筆道具只多了 `equip_level`，`_meta.version` 變成 `-r3`，其他內容不變。
- **AC-11** `[人工]` 以同一份 `data_sources.json` 連跑兩次 `build_data.py`，所有產出檔逐 byte 相同。
- **AC-12** `[diff]` 新增的使用者可見文字都走 `Localizable.xcstrings`，view 內沒有硬編字串。
- **AC-13** `[自動]` 可裝備的道具，等級文字有裝備等級與品級，裝備等級在前；不可裝備的道具、以及沒有裝備等級的裝備，只有品級 —— 新增 unit test
- **AC-14** `[人工]` 搜尋結果列表與 detail page 上，AC-9 抽查的道具顯示「Lv.<裝備等級> · iLv <品級>」，裝備等級與遊戲內相同；釣餌（例如蟲箱）只顯示「iLv <品級>」。
