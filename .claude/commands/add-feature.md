- 逐條實作，不要挑著做。
- 標記 `[自動]` 的條件要有對應的測試；已指名測試就確認它涵蓋該條件，沒指名就寫一個。
- 不要為了讓實作過關而修改驗收條件。條件本身有誤時，改它並在 PR 說明改了什麼、為什麼。
- 「不在這個 Phase」列出的事情不要順手做掉。

實作完成後跑過機械閘門再交出：`./scripts/run_tests.sh`、
`python3 scripts/validate_data.py`，以及 CLAUDE.md 裡的 build 指令。
